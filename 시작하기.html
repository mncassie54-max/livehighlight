Live Highlight & AutoCut — 처음 받으신 분을 위한 안내

어려운 건 없습니다. 까만 명령어 창에 뭘 입력하실 일은 없어요.

처음 준비하는 데 10분쯤 걸리고, 그 뒤로는 파일 하나 더블클릭이면 끝입니다.

이 두 프로그램은 뭘 해주나요?

둘 다 긴 방송 영상을 편집하는 시간을 줄여주는 도구입니다. 최종 편집은 평소처럼 프리미어 프로에서 하시고, 이 프로그램들은 그 앞 단계 — 가장 지루하고 오래 걸리는 부분 — 을 대신 해줍니다.

🔍 Live Highlight — "어디가 재밌었지?" 를 찾아줍니다

5시간짜리 라이브 방송 녹화를 처음부터 다시 보면서 쓸 만한 장면을 골라내는 작업, 그걸 없애주는 프로그램입니다.

시청자 채팅 반응(갑자기 채팅이 폭주한 곳, ㅋㅋ가 쏟아진 곳, "클립!" "편집해줘" 라고 한 곳, 후원이 몰린 곳)과 방송자 목소리(웃음소리, 갑자기 커진 리액션)를 같이 보고, 재밌었을 가능성이 높은 순서대로 구간 목록을 뽑아줍니다.

목록에서 미리보기로 확인한 다음, 마음에 드는 것만 골라 프리미어로 넘기거나 숏츠용 세로 영상(9:16)으로 바로 뽑을 수 있습니다.

✂️ AutoCut — "조용한 부분" 을 잘라줍니다

영상을 창에 끌어다 놓으면 소리를 분석해서 아무 말 없는 구간을 잘라낸 편집본을 만들어 줍니다. 목소리가 확 커지는 지점에는 표시(마커)도 찍어줍니다.

결과물은 프리미어에서 열 수 있는 파일로 나옵니다. 열어보면 이미 컷편집이 된 상태에서 작업을 시작할 수 있습니다.

영상을 새로 만들어내는 게 아니라 "여기부터 여기까지 쓴다" 는 정보만 만드는 방식이라, 100GB가 넘는 파일이나 10시간짜리 영상도 문제없이 처리합니다. 화질도 그대로입니다.

준비하기 (처음 한 번만, 10분)

  1. GitHub 계정 만들고 초대 받기

    이 프로그램들은 아무나 볼 수 없게 잠가 두었습니다. 그래서 먼저 초대를 받으셔야 합니다.

    • github.com 에서 가입합니다. 이메일과 비밀번호만 있으면 됩니다.
    • 가입할 때 정한 아이디를 공유해 주신 분께 알려주세요. 그래야 초대를 보낼 수 있습니다.
    • 초대 메일이 오면 Accept invitation(초대 수락) 버튼을 누릅니다. 프로그램이 두 개니 메일도 두 통 옵니다. 둘 다 수락해 주세요.

    메일이 안 보이면 스팸함도 확인해 보세요.

  2. GitHub Desktop 설치하기

    프로그램 파일을 내 컴퓨터로 가져오는 앱입니다. 클릭만으로 됩니다.

    • desktop.github.com 에서 내려받아 설치합니다.
    • 앱을 열고 1번에서 만든 계정으로 로그인합니다.

  3. 두 프로그램 받아오기

    앱 위쪽 메뉴에서 File(파일) → Clone repository(저장소 복제) 를 누릅니다.

    목록에 두 개가 보일 겁니다. 하나씩 두 번 받아주세요.

    목록에 이렇게 보입니다이 프로그램입니다
    livehighlight🔍 Live Highlight
    autocut✂️ AutoCut

    고르고 Clone 버튼을 누르면 잠시 뒤 다 들어옵니다.

    "어디에 저장할까요?" 하고 물어봅니다. 기본값 그대로 두셔도 되고, 나중에 찾기 쉬운 곳으로 바꾸셔도 됩니다. 어디에 저장했는지만 기억해 두세요.

실행하기

GitHub Desktop 위쪽에서 실행할 프로그램을 고른 다음, Repository(저장소) → Show in Finder(파인더에서 보기) 를 누르면 폴더가 열립니다.

폴더 안에 업데이트.command 라는 파일이 있습니다. 이게 실행 버튼이라고 생각하시면 됩니다. 두 폴더 모두 똑같이 들어 있습니다.

⚠️ 잠깐 — 처음에는 그냥 더블클릭하면 안 열립니다

맥이 "확인되지 않은 개발자가 만든 파일" 이라며 막습니다. 바이러스라서가 아니라, 애플에 돈을 내고 등록한 프로그램이 아니라서 그렇습니다.

처음 한 번만 이렇게 열어주세요:

파일을 마우스 오른쪽 버튼으로 클릭 → 열기 → (경고창이 뜨면 다시) 열기

한 번 이렇게 열고 나면, 그다음부터는 그냥 더블클릭해도 잘 열립니다. 프로그램이 두 개니 각각 한 번씩 해주셔야 합니다.

까만 창이 뜨면서 글자가 주르륵 올라갑니다. 정상입니다.

⏳ 처음 한 번은 3~5분 걸립니다

프로그램이 돌아가는 데 필요한 것들을 인터넷에서 받아오는 중입니다. 화면이 멈춘 것처럼 보여도 고장 난 게 아닙니다. 커피 한 잔 하고 오세요.

두 번째부터는 몇 초 만에 바로 뜹니다.

Live Highlight 를 쓰실 때 — 까만 창을 닫지 마세요

브라우저 화면은 까만 창이 살아 있는 동안에만 작동합니다. 까만 창을 닫으면 브라우저 화면도 더 이상 동작하지 않습니다.

다 쓰고 끝내실 때 까만 창을 닫으시면 됩니다.

브라우저가 저절로 안 열리면 주소창에 http://127.0.0.1:8777 을 직접 입력하세요. 인터넷 주소처럼 보이지만 내 컴퓨터 안에서만 도는 화면입니다.

다음부터는 이것만 하시면 됩니다

그냥 업데이트.command 를 더블클릭하세요.

프로그램을 고쳤다는 연락을 받으셨을 때도, 평소에 그냥 쓰실 때도 똑같이 이 파일입니다. 최신 버전을 알아서 받아오고 바로 실행까지 됩니다. 다시 설치하거나 뭘 지우실 필요 없습니다.

인터넷이 안 되는 곳이어도 괜찮습니다. 최신 버전을 못 받으면 지금 갖고 계신 버전으로 그냥 실행됩니다.
