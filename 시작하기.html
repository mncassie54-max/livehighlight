2 · 설치하기

파일 하나로 설치

받으신 설치.command 파일 하나만 있으면 됩니다. 계정을 만들거나 다른 앱을 깔 필요 없습니다.

⚠️ 그냥 더블클릭하면 안 열립니다

맥이 "확인되지 않은 개발자가 만든 파일" 이라며 막습니다. 바이러스라서가 아니라, 애플에 돈을 내고 등록한 프로그램이 아니라서 그렇습니다.

설치.command 를 마우스 오른쪽 버튼으로 클릭 → 열기 → (경고창이 뜨면 다시) 열기

이 경고는 이 파일 딱 한 번만 나옵니다. 설치된 프로그램들은 그냥 더블클릭으로 열립니다.

까만 창이 열리면서 두 프로그램을 내려받습니다. 보통 10~30초면 끝납니다. 끝나면 설치된 폴더가 저절로 열립니다.

서류 › 영상편집도구 › 📁 AutoCut ← ✂️ 조용한 부분 잘라내기 📁 LiveHighlight ← 🔍 재밌는 구간 찾기

이 폴더는 서류(Documents) 폴더 안 "영상편집도구" 에 만들어집니다. 자주 쓰실 거면 이 폴더를 Finder 사이드바에 끌어다 놓으시면 편합니다.

2 · 설치하기

실행하는 법

쓰고 싶은 프로그램 폴더에 들어가서 업데이트.command 를 더블클릭하면 실행됩니다. 이게 실행 버튼이라고 생각하시면 됩니다.

⏳ 각 프로그램의 첫 실행은 3~5분 걸립니다

프로그램이 돌아가는 데 필요한 것들을 인터넷에서 받아오는 중입니다. 화면이 멈춘 것처럼 보여도 고장 난 게 아닙니다. 커피 한 잔 하고 오세요. 두 번째부터는 몇 초 만에 바로 뜹니다.

프로그램이렇게 열립니다
🔍 Live Highlight 브라우저(크롬·사파리) 창이 저절로 열리면서 작업 화면이 나타납니다. 웹사이트처럼 생긴 화면에서 작업하시면 됩니다.
✂️ AutoCut 프로그램 창이 뜹니다. 여기에 영상 파일을 끌어다 놓으세요.
까만 창을 닫지 마세요

프로그램이 켜져 있는 동안 까만 창은 계속 떠 있습니다. 이 창이 프로그램 본체입니다. 닫으면 프로그램도 같이 꺼집니다. 다 쓰고 끝내실 때 닫으시면 됩니다.

3 · Live Highlight 쓰는 법

방송 전 OBS 설정 (한 번만)

마이크를 별도 트랙으로 녹음해 두면 결과가 훨씬 정확해집니다. 전체 소리에 게임 소리·BGM이 섞여 있으면 웃음소리를 구분하기 어렵기 때문입니다.

트랙 1전체 믹스 (게임 소리 + 마이크 + BGM) — 클립·숏츠에 들어갈 소리
트랙 2마이크만 — 웃음·리액션을 찾는 데 씁니다

OBS → 설정 → 출력 → 녹화 → 오디오 트랙에서 1번과 2번을 체크하고, 오디오 믹서의 톱니바퀴 → 오디오 고급 속성에서 마이크를 트랙 2에만 배정하시면 됩니다. 안 해도 동작은 합니다 — 정확도만 조금 떨어집니다.

프리미어에서 파일 → 가져오기

02

촬영본_autocut.xml 을 고릅니다

03

프로젝트 패널에 AutoCut 시퀀스가 생깁니다. 더블클릭해서 여세요

표시(마커)는 창 → 마커 패널에서 보입니다.

⚠️ 영상 파일을 옮기지 마세요

XML은 영상 파일의 위치를 가리키는 것이라, 영상을 다른 폴더로 옮기거나 이름을 바꾸면 프리미어가 화면을 못 찾습니다.

이미 옮기셨다면 프리미어에서 미디어 다시 연결(Link Media) 로 영상을 지정해 주시면 됩니다.

4 · AutoCut 쓰는 법

결과 조절하기

마음에 안 들면 설정을 바꾸고 같은 영상을 다시 끌어다 놓으면 됩니다. 결과 파일은 덮어써집니다.

설정기본값무슨 뜻인가
무음 임계값-40 dB 이 음량보다 조용하면 "침묵" 으로 봅니다. 올리면 더 많이 잘리고, 내리면 덜 잘립니다
무음 최소 길이0.5초 이보다 짧은 침묵은 두고 갑니다. 말 사이 숨 쉬는 틈을 지키려는 값입니다
강조 민감도1.0높이면 표시(마커)가 많아집니다
강조 마커 표시켬끄면 표시 없이 자르기만 합니다
mkv로 녹화하신다면

프리미어는 .mkv 를 못 읽습니다. OBS 기본 포맷이 mkv라서, AutoCut이 화질 손실 없이 mp4로 다시 포장하고 그 파일을 가리키게 합니다. 원본은 그대로 두니 따로 하실 일은 없습니다.

5 · 평소 쓰기

매번 이것만 하면 됩니다

프로그램 폴더의 업데이트.command 를 더블클릭

프로그램을 고쳤다는 연락을 받으셨을 때도, 평소에 그냥 쓰실 때도 똑같이 이 파일입니다. 최신 버전을 알아서 받아오고 바로 실행까지 됩니다. 다시 설치하거나 뭘 지우실 필요 없습니다.

인터넷이 안 되는 곳이어도 괜찮습니다. 최신 버전을 못 받으면 지금 갖고 계신 버전으로 그냥 실행됩니다.

6 · 막혔을 때

문제 해결

이런 일이 생기면이렇게 해보세요
"확인되지 않은 개발자" 라고 뜬다파일을 오른쪽 클릭 → 열기 → 열기
까만 창이 뜨자마자 사라진다오른쪽 클릭 → 열기 로 다시 해보세요
한참 아무 반응이 없다첫 실행이라면 정상입니다. 5분은 기다려 주세요
브라우저가 저절로 안 열린다
Live Highlight		 주소창에 http://127.0.0.1:8777 직접 입력
화면이 갑자기 안 된다
Live Highlight		 까만 창이 닫히지 않았는지 확인해 주세요
찾아준 구간이 전부 엉뚱하다
Live Highlight		 시간 맞추기 를 다시 해보세요. 대부분 이 문제입니다
프리미어에서 화면이 안 보인다
AutoCut		 영상 파일을 옮기셨는지 확인. 미디어 다시 연결 로 지정해 주세요
"업데이트를 받지 못했습니다"그냥 쓰셔도 됩니다. 인터넷 연결을 확인해 보세요
